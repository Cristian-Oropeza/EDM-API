# EDM-API

Proyecto personal full stack con API REST en NestJS y cliente web, estructurado como monorepo.

## Estructura

```
EDM-API/      Backend NestJS (TypeScript)
EDM-Client/   Cliente web
```

## Stack

- **Backend:** NestJS · TypeScript
- **Cliente:** Web
